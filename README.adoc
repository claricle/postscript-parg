= postscript-parg

The PostScript grammar in https://github.com/parsanol/parsanol-rs[PARG] —
the parsanol grammar language (ABNF-flavoured, PEG semantics).

This repository is the canonical home of the grammar and its compiled
artifact; the https://github.com/claricle/postscript[postscript] gem
consumes the artifact for its native parser path
(claricle/postscript#4).

== Normative source

The grammar is developed according to the
https://claricle.github.io/postscript-guide/[PostScript Language Guide]
(claricle/postscript-guide): `docs/syntax/*` defines the token and
literal rules, `docs/commands/**` the operator vocabulary, and
`docs/levels/*` the Level 1/2/3 feature gating the grammar must
express.

== Layout

* `postscript.parg` — the grammar source (the contract); each rule
  cites the guide page it derives from
* `postscript.json` — the compiled artifact (checksummed envelope),
  compiled with the released parsanol:
+
----
parsanol parg compile postscript.parg -o postscript.json
----

== CI

CI installs the released `parsanol` gem and runs, on every push/PR:

* `parsanol parg test postscript.parg` — the grammar's embedded
  accept/reject smoke tests
* a fresh compile checked for *payload parity* against the committed
  artifact (envelope metadata — `checksum`, `compiler_version` —
  stripped, since those legitimately change with each parsanol
  release; the grammar payload must not)

== Status

Framework — the token/literal grammar (whitespace, comments and DSC,
integers/reals/radix, literal and hex strings with escapes and
nesting, names, arrays/procedures/dictionaries) with embedded smoke
tests; the grammar is level-agnostic (see claricle/postscript#4).
The operator vocabulary stays registry metadata in the postscript gem.
